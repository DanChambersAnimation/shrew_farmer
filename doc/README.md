# Design docs

Running logs for the game's design. Add to them freely. Short entries are fine, and an idea doesn't need to be finished to go in.

| File                           | What goes in it                                                                           |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| [gambits.md](gambits.md)       | Gambits, power-ups and equipment: what they do, their upsides and their risks.            |
| [ideas.md](ideas.md)           | Ideas not yet scheduled: mechanics, rooms, effects, anything else.                        |
| [features.md](features.md)     | Features that exist in the game, what they do, and where to try them.                     |
| [principles.md](principles.md) | The design rules everything follows.                                                      |
| [plans/](plans/)               | Plans for larger pieces of work, e.g. [sound_and_speech1.md](plans/sound_and_speech1.md). |

## How to use these

- **Something new to try?** Add it to `ideas.md` (or `gambits.md` if it's something the Speaker uses).
- **Ready to build?** Open a GitHub issue and link it from the entry. The issue tracks the work; the doc keeps the design.
- **Built?** Move or summarise it in `features.md`, with the room where it can be seen.
- **A big piece of work?** Write a plan under `plans/` first, so the design is reviewable before it is built.
